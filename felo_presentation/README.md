# How to Generate the FloodSafe Presentation in Felo

Follow these 3 simple steps on [felo.ai](https://felo.ai):

### Step 1: Open Felo PPT Generator
1. Go to **[https://felo.ai](https://felo.ai)**.
2. Click on **Create PPT** / **Presentation**.

### Step 2: Upload or Paste Content
Choose either of these two methods:

* **Method A (Easiest — File Upload)**:
  1. Click the **Upload File / Document** button (📎 or 📄 icon).
  2. Upload [`PRESENTATION_CONTENT.md`](file:///d:/codeverse/hackathons/AI%20WATER%20HACKATHON/felo_presentation/PRESENTATION_CONTENT.md) (or both `.md` files in this folder).
  3. In the prompt box, paste the text from [`PROMPT_FOR_FELO.txt`](file:///d:/codeverse/hackathons/AI%20WATER%20HACKATHON/felo_presentation/PROMPT_FOR_FELO.txt).

* **Method B (Direct Paste)**:
  1. Open [`PRESENTATION_CONTENT.md`](file:///d:/codeverse/hackathons/AI%20WATER%20HACKATHON/felo_presentation/PRESENTATION_CONTENT.md).
  2. Copy everything and paste it directly into the Felo topic prompt box.

### Step 3: Choose Theme & Generate
1. Pick a **Modern Tech Dark** or **Environmental / Clean Tech Blue** theme.
2. Select **8 to 10 slides**.
3. Click **Generate Presentation**.
